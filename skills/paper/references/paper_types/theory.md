# 理论 / 数学推导论文

包括：学习理论（泛化界、样本复杂度）、优化理论（收敛率）、概率与集中不等式、信息论、统计估计理论、博弈论与机制设计、复杂度下界、随机矩阵、降维（Johnson–Lindenstrauss）。

核心思路：定理无法用代码"证明"，但代码可以做三件很有价值的事：**让抽象的结论变得可见**、**检查推导的关键步骤**、**探索假设的边界**。

## 实现什么

- **定理中涉及的构造**：论文构造了某个算法、估计量、随机映射、反例时，把它实现出来。
- **定理的量**：界的两侧都要能计算，经验量（从模拟中测）和理论界（按公式算）。

## 讲解定理

每个主要定理按这个顺序讲：
1. **白话陈述**：去掉所有符号，这个定理在说什么？为什么有人关心？
2. **形式陈述**：原文公式，逐个解释量词、常数、假设条件。
3. **假设清单**：列出每条假设，说明它为什么需要（去掉它证明哪一步会断）。
4. **证明思路**：先给一段话的整体策略（"先用 union bound 把问题拆开，再对每一项用 Hoeffding"），再按关键步骤展开。不需要复述每一行，重点讲**不显然的步骤**，并说明"为什么想到这一步"。
5. **数值验证**（下面）。

## 验证方法

### 符号验证（sympy）

推导中的代数步骤、求导、泰勒展开、积分、极限，用 `sympy` 核验：

```python
import sympy as sp
x, t = sp.symbols("x t", positive=True)
lhs = sp.log(1 + x)
series = sp.series(lhs, x, 0, 4).removeO()
print("log(1+x) ≈", series)
assert sp.simplify(sp.diff(series, x).subs(x, 0) - 1) == 0
```

适合放在证明思路的对应步骤旁边。

### 经验 vs 理论界

- 在满足假设的随机实例上测量经验量，与理论界画在同一张图上，扫描关键参数（样本量 n、维度 d、失败概率 δ）。
- 观察三件事：界是否成立（经验量始终在界内）、**界有多紧**（差多少倍）、**标度是否一致**（log-log 图上斜率是否一致，例如 $O(1/\sqrt{n})$ 对应斜率 −1/2）。
- 概率性结论（以至少 $1-\delta$ 的概率）：大量重复实验，统计违反比例，报告置信区间（Wilson 区间或二项分布正态近似）。

### 探索假设边界

- **违反假设**：构造一个违反某条假设的实例，展示结论失效（例如非凸函数下梯度下降收敛到非全局最优；重尾分布下 Hoeffding 界失效）。这能让读者真正理解假设为什么存在。
- **下界/最优性**：论文声称界是紧的时，实现论文中达到界的困难实例，展示经验量确实接近界。

### 小规模穷举

离散问题（组合、博弈、布尔函数）在小规模下可以穷举所有情况，直接验证定理在 n ≤ 某个小值时成立，并寻找反例。

## 高价值可视化

- 理论界 vs 经验值随参数变化（log-log，带参考斜率线）
- 经验分布直方图 + 集中不等式给出的尾部界
- 优化轨迹叠加在等高线图上（收敛率类论文）
- 高维现象的低维直观：随机投影前后距离比的分布（JL 引理）、高维球体积集中

## 常见陷阱

- 理论界的常数通常很宽松，经验量远小于界是正常的，重点看标度是否一致，不要误以为"验证失败"。
- 渐进结论（n → ∞）在小 n 下可能看不出来，扫描范围要足够大，并在笔记中说明。
- 数值精度：概率很小的事件、极大/极小的量用 log 空间计算（`scipy.special.logsumexp`）。
- 避免在 notebook 里写很长的形式化证明，那是论文的职责。notebook 的价值在于直觉、关键步骤的解释和数值验证。
