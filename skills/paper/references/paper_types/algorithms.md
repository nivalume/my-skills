# 经典算法 / 数据结构论文

包括：排序与搜索、图算法、字符串算法、树与哈希结构、概率数据结构（Bloom filter、HyperLogLog、Count-Min Sketch、Skip list）、近似与随机算法、在线算法、并发/无锁数据结构。

## 实现什么

- **忠实实现论文的算法**，包括论文强调的优化细节（这些细节往往就是论文的贡献）。伪代码有编号时，代码注释中标行号：`# Alg. 1, line 7`。
- 实现一个**朴素 baseline** 用于对比（论文通常会和它比较）。
- 实现一个**暴力 oracle**：简单到显然正确的版本，只用于测试。
- 用 Python 实现时优先清晰；性能实验测量**操作次数**（比较次数、探测次数、访存次数、旋转次数），而非只看墙钟时间，因为 Python 解释器的常数开销会掩盖渐进行为。

## 正确性检查

- **随机差分测试**：在大量随机小输入上对比实现与 oracle 的输出。不需要额外依赖：

  ```python
  def differential_test(impl, oracle, gen_input, trials=2000):
      for t in range(trials):
          x = gen_input(rng)
          a, b = impl(x), oracle(x)
          assert a == b, f"mismatch on trial {t}: input={x!r} impl={a!r} oracle={b!r}"
      print(f"✓ {trials} random trials passed")
  ```

- **不变量断言**：数据结构提供 `check_invariants()` 方法，测试中每次操作后调用（红黑树颜色性质、堆性质、跳表层级有序、B-tree 节点填充率）。
- **边界与对抗输入**：空输入、单元素、全相同、已排序、逆序、论文分析中的最坏情况构造。
- **概率数据结构**：正确性是统计意义的，见下方"概率保证"。

## 验证实验设计

### 复杂度

- 输入规模按几何级数取值（如 2^8 到 2^16），每个规模多次运行。
- 画 **log-log 图**，用 `np.polyfit(np.log(n), np.log(cost), 1)` 拟合斜率，和论文声称的复杂度对比（O(n log n) 在 log-log 上的斜率略大于 1，可以同时画 `n log n` 参考线）。
- 同时画平均情况和论文分析的最坏情况。
- 摊还分析的论文：画每次操作的代价序列和累计平均代价，直观展示"偶尔昂贵、平均便宜"。

### 概率保证

- 论文给出误差界（如 Bloom filter 的误判率 $(1-e^{-kn/m})^k$、HyperLogLog 的标准误差 $1.04/\sqrt{m}$）时：多次独立实验测量经验值，与理论曲线画在同一张图上，扫描关键参数（m、k、n）。
- 报告经验分布（直方图或分位数），而不仅是均值。
- 高概率界（"以至少 $1-\delta$ 的概率"）：统计违反界的比例，对比 $\delta$。

### 与 baseline 对比

- 在论文强调的场景下（例如特定的数据分布、读写比例）对比新算法和 baseline。
- 也构造一个新算法**不占优**的场景，说明它的适用边界。

## 高价值可视化

- **状态演变**：数据结构在一系列操作后的形态（用 matplotlib 画树/链表/哈希表，节点用 `ax.text` + `bbox`，边用 `ax.annotate` 箭头）。避免引入 networkx/graphviz 依赖，除非结构复杂到必须。
- **算法执行轨迹**：例如每一步的搜索区间、优先队列内容、图遍历的访问顺序（逐帧子图）。
- **理论 vs 经验**曲线（误差率、复杂度）。
- **参数权衡**：空间 vs 误差、时间 vs 精度的 Pareto 图。

## 并发 / 无锁数据结构

Python 的 GIL 使真实并发测试意义有限。改用：
- **显式调度模拟**：把每个操作拆成原子步骤（生成器 `yield` 每步），由调度器随机交错执行，大量随机调度下检查线性一致性（linearizability）或不变量。
- 构造论文里描述的**危险交错**（如 ABA 问题），展示朴素实现出错、论文方法正确。

## 常见陷阱

- 老论文（1970s–1990s）常常是扫描件，伪代码可能用 Pascal/ALGOL 风格，数组下标从 1 开始，注意转换。
- 论文伪代码可能省略了边界处理，实现时补全并标注 `⚠️ 论文未明确`。
- 哈希函数：概率数据结构的理论假设理想随机哈希，实现时说明所用哈希（例如 `hashlib.blake2b` 加盐）及其对结果的影响。
