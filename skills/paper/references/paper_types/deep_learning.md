# 深度学习 / 模型架构论文

## 实现什么

- **核心新组件优先**：论文提出的新 layer、loss、优化器、训练技巧。标准组件（普通 MLP、LayerNorm）可以直接用框架自带的。
- **两层实现法**（适合核心算子，如 attention、新的归一化、新的位置编码）：
  1. 先用 **numpy** 从零写一遍前向计算，逐步打印中间结果，帮助理解
  2. 再用 **torch** 写一个可训练版本，用于实验
  3. 用 `np.allclose` 检查两者前向输出一致
- 只有概念简单的论文可以只用 torch。
- 模型规模按 toy 设定：几层、几十到几百维、几千到几万参数。

## 正确性检查

- **Shape 检查**：每个张量操作后在注释中写 shape，关键位置用 `assert x.shape == (B, T, D)`。
- **参数量核对**：如果论文给出参数量公式或表格，用代码计算参数量并与论文公式（按 toy 配置代入）比较。
- **梯度检查**：自定义 backward 或自定义 loss 时，用有限差分或 `torch.autograd.gradcheck`（需 `float64`）验证。
- **不变性/等变性**：论文声称的性质直接测，例如置换等变（打乱输入顺序输出同样被打乱）、缩放不变。
- **退化情形**：新组件在特定参数下应退化为已知组件时（例如某个系数为 0 时退化为标准 attention），验证这一点。
- **过拟合小批量**：模型能在 32 个样本上把 loss 降到接近 0，是实现没有大错的基本信号。

## 验证实验设计

关键是设计一个**合成任务，让论文声称的优势能在小规模下显现**。例如：

| 论文 claim | toy 任务 |
|---|---|
| attention 能捕获长距离依赖 | copy / reverse 序列任务，逐渐增加序列长度，对比 RNN |
| 新位置编码能长度外推 | 在长度 ≤ 32 上训练，在 64、128 上测试 |
| 新归一化让训练更稳定 | 较大学习率下对比 loss 曲线和梯度范数 |
| 新优化器收敛更快 | Rosenbrock 函数、病态二次型、小 MLP |
| 残差连接缓解退化 | 深而窄的 plain net vs ResNet，相同参数量 |
| 对比学习 loss 学到好表示 | 2D 合成聚类数据，可视化 embedding |

实验规范：
- **消融**：有/无关键组件，其余完全相同。
- **多种子**：至少 3 个种子，报告均值 ± 标准差，画 `fill_between`。
- **公平比较**：对比方法用相近的参数量和相同的训练步数，并在笔记中注明。
- **复杂度实测**：论文声称复杂度（例如 O(n²) vs O(n)）时，测量不同序列长度下的时间和峰值内存，画 log-log 图并拟合斜率。

## 高价值可视化

- attention 权重热力图（在有明确结构的合成任务上，可以看出模型学到了什么模式）
- 训练曲线：loss、梯度范数、学习率 schedule
- 激活值 / 梯度的分布随层数的变化（归一化、初始化类论文）
- 2D embedding 可视化（PCA 或直接用 2 维）
- 超参数扫描热力图
